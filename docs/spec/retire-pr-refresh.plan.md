# 退役 Runner PR 刷新实施 Plan

对应[Spec](retire-pr-refresh.spec.md)。实施从最新 main 的独立 worktree 进行。

1. 移除 CLI 参数、宿主请求字段、Engine 刷新分支及刷新专用错误字段。更新内部调用和当前 CLI 说明，保留工作流发布、绑定和普通快照读取。
2. 把受控验收切换到验证原发布和早期绑定，覆盖旧参数拒绝，以及平台漂移时 inspect 不查询、不写回、不派发。迁移原生验收到独立平台取证，并同步证据文件及校验器，保留合入身份、确切 head、时间、merge commit 和 Git 内容检查。
3. 运行受影响包和公开接口的定向回归，编译原生验收并运行独立平台证据校验测试。实际原生或平台测试资格按报告登记。交付前审计 CLI、宿主、Engine、测试和当前文档，区分历史记录和有意保留的拒绝测试，记录结果后提独立 PR。
