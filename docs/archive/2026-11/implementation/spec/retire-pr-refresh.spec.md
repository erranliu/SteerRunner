# 退役 Runner 的 PR 刷新入口

> 2026-11-06 归入历史实施材料（整理基线 `dda9a827`）。正文中的状态、日期、构建和资格按原记录时点阅读；归档不表示所述机制失效，也不把未验项改成通过。现行入口见[文档索引](../../../../README.md)；[迁移清单](../README.md)。

SteerLine #445 已将 TaskDelivery 和 TaskDiscard 的实时合入查询切换到平台。本项退役 Runner 公开 `inspect --refresh-pr`，调用方按现行接口直接查询平台。对应[实施 Plan](retire-pr-refresh.plan.md)。

## 边界

- 普通和离线 `inspect` 读取原持久快照。移除刷新参数、宿主请求字段、查询写回和刷新事件。旧参数按未知参数拒绝，无兼容入口。
- Runner 自行推进 Workflow，继续核验发布、绑定原 PR，以及适用时核对已审计提交。保留独立的早期 PR 线索绑定及现有 PR 身份、合入字段和观察时间。刷新专用的 PR 查询错误字段随入口退役。
- 实时合入证据由平台提供。原生验收从 Runner 取得已绑定 PR 的身份和 head，以独立平台查询核对同一 PR 的当前 head 和合入结果。平台观察独立留证，保留确切 head 合并、Git 对象和内容验证。

## 通过条件

CLI 拒绝旧参数。普通 inspect 在平台数据变化后仍返回原观察，查询次数、Run revision、输入次数保持稳定。早期绑定和自主发布仍成立。验收驱动与报告读取使用平台证据，校验原 PR 身份、合入时间、提交及分支内容。活跃生产入口中没有刷新协议字段或刷新写回路径。
